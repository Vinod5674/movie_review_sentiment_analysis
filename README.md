# 🎬 Movie Review Sentiment Analysis

A Machine Learning + NLP project that predicts whether a movie review is **Positive** or **Negative**.

---

## 📌 Project Overview

This project uses Natural Language Processing (NLP) techniques and Machine Learning to analyze movie reviews and classify them into positive or negative sentiments.

---

## ✨ Features

- Predicts Positive or Negative sentiment
- Text preprocessing using NLP
- TF-IDF Vectorization
- Trained Machine Learning Model
- Flask Web Application
- Simple and Responsive UI

---

## 🛠️ Technologies Used

- Python
- Flask

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/YourUsername/Movie-Review-Sentiment-Analysis.git
```

Move into project folder

```bash
cd Movie-Review-Sentiment-Analysis
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the Flask application

```bash
python app.py
```

Open

```
http://127.0.0.1:5000
```
